# Banking System

This was my first project after learning Python. I tried to create a
console-based banking environment inspired by a real-world banking system,
built entirely with Python.

The system includes user authentication, account management, transaction
handling, and flat-file data persistence to maintain account state across
sessions.

## Features

- User registration and authentication
- Account management
- Deposit and withdrawal functionality
- Transaction handling
- Persistent data storage using files
- Console-based interface
- Input validation and error handling



- ## Technologies Used

- Python
- File Handling
- Object-Oriented Programming
- Exception Handling
- Data Validation
